Post-processing for data from Large Eddy Simulations (LES) of Marine Atmospheric Boundary Layers with wave drag model including a slip factor in the local subfilter wave drag.

### bottom_slice/
Generates plot of the xy-plane at the bottom of the domain showing the filtered velocity at the bottom-most cell $\widetilde{u}_b$, resolved drag $F_D$, local dynamic parameter $\alpha_w$, dynamic parameter flucutations $\log(\alpha_w)-\log(\langle \alpha_w\rangle)$, and subfilter roughness $z\_{0,\Delta}$ at the air-sea surface for two LES cases.

- U18_HS12_kp*.csv : text data files
- alice.py : python class to process text file
- visualize_alpha_xy.ipynb : jupyter notebook to create plot of the bottom xy-plane

### parameter_sweep/
Processes data from a sweep of LES cases varying wind and wave parameters.

- data/ : contains averaged statistics from individual LES runs
  - sf_case_log.xslx : excel spreadsheet containing case information for all runs
- ext_data/ : external data (from field campaigns)
  - TauDataEdson.mat : aggregated data from Edson et al. (2013)
  - romero.csv : from the GOTEX field campaign, Romero et al. (2010)
- figures/ : contains generated figures
- helpers.py : functions to create list of stat objects and plot different profiles
- analyze_slip_stat.ipynb : jupyter notebook to generate plots

### sliptools/
- statData.py : python class to read and create object from LES stat files generated by NGA
